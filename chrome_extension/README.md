# 早耳字幕（Chrome 拡張機能）

PC で動いている早耳（`realtime_transcribe.py --serve`）の字幕を、Chrome のサイドパネルに表示する拡張機能です。

- 音声は扱いません。早耳が PC の中で作った字幕の文字を、`http://127.0.0.1:8833/events` から受け取って表示するだけです。
- 外部への通信はありません（フォントも PC に入っているものを使います）。
- 早耳が拾う音は今までどおりです。`--input speaker` なら、Zoom アプリや Slack ハドルなど、PC から出る相手の声が字幕になります。

## 入れ方

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダ（`chrome_extension`）を選ぶ
4. ツールバーのパズルのアイコンから「早耳字幕」をピン留めする

## 使い方

1. 早耳を `--serve` 付きで起動する（例：`python scripts\realtime_transcribe.py --mode single --lang ja --input speaker --serve`）
2. ツールバーの「早耳字幕」のアイコンを押すと、右側に字幕のパネルが開く

| 画面 | 内容 |
|---|---|
| 字幕 | 確定した文を、時刻付きで並べる（新しいものが下）。下の「いま聞き取り中」に話している途中の文が出る |
| 清書 | 話の切れ目（約2秒の無音）ごとに読み直した文章。パネルを開く前の内容も、早耳が覚えている分（最大200件）は表示される |
| A− / A＋ | 文字の大きさ（次回も同じ大きさで開く） |
| コピー | 表示中の画面の字幕を、時刻付きでまとめてコピー |
| クリア | パネルの表示を消す（早耳側の記録は消えない） |

- 早耳が動いていないときは、パネルにそう表示され、起動すると自動でつながります。
- 上にスクロールして読み返している間は、新しい字幕が来ても勝手に下へ動きません。「最新へ ↓」で最新に戻ります。

## 制限

- 接続先は `127.0.0.1:8833`（早耳の `--serve` の既定値）に固定しています。
- サイドパネルは Chrome の窓の中に表示されます。Zoom アプリを全画面にしているときなど、Chrome が隠れていると見えません。
